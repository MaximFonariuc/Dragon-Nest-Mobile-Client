## TPNS 提供给 MSDKV3 使用的华为推送 V5 SDK

### 相关版本
hms push 版本：6.7.0.300
tpns huawei 插件版本：1.3.7.2

### 封装内容
- AndroidManifest.xml：hms push 全部 manifest 内容 + TPNS-SDK-huawei 插件依赖包 manifest 内容
- libs：hms push 全部 aar 内 jar 包的内容
- assets：hms push 全部 assets 内容
- res：hms push 全部 res 内容
- tpns-huaweiv5-*.jar：TPNS-SDK-huawei 插件依赖 jar 包
